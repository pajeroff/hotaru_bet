# Хотару (Hotaru) — прототип

Уютный медитативный прототип на **Godot 4.7.2**: остров, древний храм, смена времени суток и погоды, ловля светлячков.

## Запуск
1. Установите [Godot 4.7.2](https://godotengine.org/download/) (стандартная сборка, без .NET).
2. Откройте `project.godot` в редакторе и нажмите ▶ (F5).

Всё содержимое (графика, звук, музыка) генерируется процедурно — внешних ассетов нет.

## Управление (переназначается в настройках)
| Действие | Клавиша |
|---|---|
| Движение | WASD / стрелки |
| Поймать светлячка | E |
| Открыть банку | I |
| Фонарь | F |
| Пауза | Esc |

## Структура
```
project.godot              настройки проекта, действия ввода
default_bus_layout.tres    аудиошины Master / Music / SFX
scenes/ui/*.tscn           главное меню, загрузка, настройки
scenes/world/world.tscn    игровой мир
scripts/autoload/          Settings, GameState, SaveManager, AudioManager, SceneRouter
scripts/ui/                тема, меню, HUD, банка, пауза
scripts/world/             поляна, храм, камера, атмосфера, менеджер светлячков, отражения в пруду
scripts/entities/          игрок, светлячок, каталог видов
```

## Что реализовано (по ТЗ)
- Главное меню с фоном, светлячками и музыкой; Продолжить / Новая игра / Загрузить / Настройки / Выход.
- 3 слота сохранения (дата, день, уровень храма, подпись), удаление с подтверждением.
- Настройки: графика (полный экран, разрешение, VSync, частицы, яркость), звук (3 громкости), управление (переназначение + сброс), игра (скорость времени, язык RU/EN). Применяются сразу, сохраняются в `user://settings.cfg`.
- Поляна с травой, тропинками, прудом, кустами и деревьями; храм с пульсирующим светом и тремя уровнями яркости.
- Игрок с 8-направленным движением, анимацией ходьбы, шагами, фонарём; трава расступается под ногами; камера с лёгким покачиванием.
- Сутки за 20 минут, 6 фаз, плавная смена света; 7 типов погоды с частицами, туманом, вспышками грозы, звуком.
- Светлячки 8 видов с характерами (дружелюбные, пугливые, любопытные, скрытные), спавн зависит от фазы и погоды; шлейф, пульсация, свет.
- Ловля по E, банка на 4 слота (обычный 1 / редкий 2 / легендарный 3), просмотр и отпускание, переполнение → светлячки тускнеют.
- Пауза, ручное сохранение в слот, автосохранение каждые 2 минуты и при выходе в меню.
- Атмосфера: звёзды ночью, отражения в пруду, листья и лепестки, эхо другого игрока, шёпоты в тумане, адаптивная музыка.

## Графика
- `art_src/` — исходные сгенерированные листы (magenta-key), `assets/sprites` и `assets/textures` — нарезанные ассеты с альфой.
- `shaders/` — земля с тропинками (`ground`), вода с преломлением (`water`), ветер в листве (`wind_sway`), объёмный туман (`fog`), свечение храма (`glow_sprite`), пост-обработка bloom/виньетка/тонировка (`post`).
- Освещение: `PointLight2D` с мягкими тенями (PCF13) у храма и фонаря игрока, `LightOccluder2D` у деревьев/камней/храма; Y-сортировка объектов; GPU-частицы для дождя/снега/лепестков, искр храма, пыли из-под ног и шлейфов светлячков.
